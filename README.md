# 万物生长 · 品牌官网（日光茶感版）

双击 **`index.html`** 即可在本地打开。多页站点，无需服务器、无需构建、无外部依赖。

这一版按“饮料要先让人想喝”重做：**暖米白 + 茶绿 + 桂黄**，没有黑色高级感；首页开头是**大幅产品图 + 明确的标题、规格和 CTA**。六个页面都在日光/纸感底色上，产品图像占主导。

## 页面

| 文件 | 页面 | 主要内容 |
| --- | --- | --- |
| `index.html` | 首页 | 大幅产品图 hero、三种香气、回甘曲线、40 份问卷、渠道 CTA |
| `products.html` | 产品 | 三风味切换、香气/口感/搭配、包装解剖、回甘曲线、规格 |
| `brand.html` | 品牌 | 品牌信念、山/水/杯三段旅程、色彩与字标、海报与周边、灯箱 |
| `survey.html` | 调查 | 四个关键数、四组数据条、三个结论、调查方法与边界 |
| `find.html` | 寻找 | 渠道与价格带、试饮预约（本地演示表单）、常见问题 |
| `register.html` | 注册 | 3 步茶友档案：基本信息 → 口味/场景 → 确认；模拟验证码与本机会员卡 |

首页、四个内页和注册页的开头都采用「左侧标题信息 + 右侧大图」结构；页面下方继续用产品、茶园、海报等大图承接。

## 可以操作的地方

- 顶部导航吸顶；移动端全屏菜单（浅色）。
- 产品页三风味切换：点击 / 键盘左右键；详情、香气条与强调色同步。
- 回甘曲线：万物生长 / 普通甜饮切换。
- 品牌页海报与周边：灯箱、上一张 / 下一张、ESC 关闭。
- 寻找页：表单校验、错误提示、成功态；不会发送或保存数据。
- 注册页 3 步流程：模拟验证码 `246810`、逐步校验、口味/场景多选、确认后生成本机会员卡；刷新后可继续查看或重新注册。
- 全站滚动显现、图片懒加载、页面切换淡出；支持 `prefers-reduced-motion`。
- 键盘可操作；弹层打开时背景 `inert`；跳转链接、焦点样式、图片替代文字齐备。

## 放到 GitHub Pages

1. 新建仓库，把本文件夹内的文件放到仓库根目录（`index.html` 在根目录）。
2. 仓库 Settings → Pages → Deploy from a branch → 选 `main` / `root`。
3. 等待生成链接即可。所有路径均为相对路径，本地与线上是同一套文件。
4. 上线后可补 `og:image` 与绝对 URL；本地版不依赖这些。

## 数据与声明

- 问卷 n=40，课堂样本，仅用于概念方向判断，不代表全市场；多选题目合计大于 100%，未做显著性检验。
- 项目为课程概念设计，非娃哈哈官方页面，未获品牌授权，不用于商业用途。
- 产品、包装、场景图像为 AI 辅助生成的概念视觉；价格、配料、渠道、试饮安排均为课程方案设定，最终以实际产品与官方信息为准。
- 试饮表单只在前端演示，不会提交到服务器，也不会持久化保存。
- 注册只在前端演示：验证码固定 `246810`，档案只写入本机 `localStorage`，不会上传服务器；请勿填写真实敏感信息。
